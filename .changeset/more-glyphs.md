New icons: `code`, `file`, `box` (a package; `package` is a reserved word in ES modules), `sliders`, `externalLink`, `terminal`, `markdown` and `github` (GitHub's mark, for links to GitHub). The names join `iconNameList` in core. The docs kit uses them instead of inline SVG strings.
