# ProgressBar

Determinate progress indicator.

## When to use which

- **ProgressBar** shows how far an operation has got: an upload, an install, a multi-step task. It ends.
- **[ProgressCircle](/components/progress-circle)** is the same thing in a ring, for tight spaces, buttons and dashboards.
- **[Meter](/components/meter)** shows a measurement inside a known range with no task in flight: disk usage, password strength, a score. Its tone says whether the value is good.
- **Spinner** is for waits with no measurable progress.
