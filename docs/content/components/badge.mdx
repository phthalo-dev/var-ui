### Colors

`tone` means status (success, warning, danger). For identity, such as an agent role, an event
kind or a label, use `color` with any name from the base palette: `blue`, `red`, `sage` and the
rest. Each color adapts to color mode and is readable as text on the surface (WCAG AA), in every
`appearance`. `StatusDot` takes `color` too.

<Demo id="badge.colors" />

For chart series, `color.categorical.1`–`8` lists eight of these hues in an order where
neighbours differ most.
