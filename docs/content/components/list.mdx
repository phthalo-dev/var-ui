# List

Structured vertical list with `List.Item` rows for labels, descriptions, and optional start/end content. Supports compound children or an `items` array.

## Accessibility

Renders a `<ul>` (or `<ol>` when `listStyle="decimal"`). Interactive rows use an invisible overlay as the sole hit target — do not nest links or buttons in `startContent` / `endContent` on those rows. Prefer string `label`s so the overlay gets a clear accessible name.
