# Toc

In-page table of contents. Pass a flat `items` list, compose manual `Toc.Item`s, or enable `auto` to scan headings in a content root. Priority is `items`, then children, then `auto`.

## Examples

### Default

A flat list of section anchors with one selected item.

<Demo id="toc.default" />

### Nested items

Mark subsection links with `nested` (matches auto mode’s `h3` indent).

<Demo id="toc.nested" />

### Items list

Pass `items` (`{ id, text, level }`; `level: 3` nests) and a controlled `activeId`. `activeId` overrides the scroll spy for `items` and `auto` lists. Available in React and Astro.

## Accessibility

The root is a `nav` landmark. Selected items set `aria-current="location"`. Prefer stable heading `id`s so `href="#…"` targets resolve.
