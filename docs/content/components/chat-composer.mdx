# ChatComposer

Bordered composer chrome around the message input and trailing actions. Pair with `ChatComposerInput` for the auto-resizing textarea and `ChatSendButton` for send/stop.

## Examples

### Default

There is no `@var-ui/astro` ChatComposer — Astro and HTML previews show static core-recipe chrome; Enter-to-submit is React-only.

## ChatComposerInput

| Prop            | Type                      | Default             |
| --------------- | ------------------------- | ------------------- |
| `value`         | `string`                  | (required)          |
| `onValueChange` | `(value: string) => void` | (required)          |
| `onSubmit`      | `(value: string) => void` | (required)          |
| `submitOn`      | `'enter' \| 'mod+enter'`  | `'enter'`           |
| `placeholder`   | `string`                  | `'Type a message…'` |
| `maxRows`       | `number`                  | `8`                 |
| `disabled`      | `boolean`                 | `false`             |
| `className`     | `string`                  | —                   |

With the default `submitOn="enter"`, Enter submits (trimmed, non-empty only) and Shift+Enter inserts a newline. `submitOn="mod+enter"` submits on ⌘/Ctrl+Enter and lets every Enter insert newlines.
