# Drawer

Slide-over panel for secondary flows (settings, details, filters). Built on React Aria Modal with focus trap, Escape, and backdrop dismissal. `Drawer` is the compound Root (`Drawer.Trigger`, `Drawer.Backdrop`, `Drawer.Popup`, `Drawer.Header`, `Drawer.Title`, `Drawer.Close`, `Drawer.Body`) with `open` / `defaultOpen` / `onOpenChange(open, details)`. `portalContainer` and `dismissable` are Root props. A `Drawer.Trigger` or `Drawer.Close` child must forward DOM props (a `Button` or a host element) — there is no `render` prop.

There is no assembled preset: the recipe below (trigger, backdrop, popup with a header, title, close and body) is the usual arrangement, so copy it and change what you need.

State attributes, exit animation, and `onOpenChange` details are documented in [Overlay lifecycle](/docs/overlay-lifecycle).

## Accessibility

Focus moves into the popup when opened and returns to the trigger on close. Name the dialog with `aria-label` / `aria-labelledby` on `Drawer.Popup` (or `aria-label` on the Root). The close control defaults to `aria-label="Close"`. Prefer drawers for multi-step or longer secondary UI; use `AlertDialog` for short confirmations.
