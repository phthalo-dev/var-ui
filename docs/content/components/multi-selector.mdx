# MultiSelector

Dropdown that selects multiple options at once. Always controlled via `value` (option values) and `onValueChange`. The trigger summarizes the current selection as a comma-separated label list.

## Examples

### Default

Pass `options` as `{ value, label, disabled? }[]` and seed `value` with the selected values.

<Demo id="multi-selector.default" />

### Controlled selection

Keep the selected values in React state and update them from `onValueChange`. The trigger text and any app UI that depends on the selection stay in sync.

## Accessibility

The trigger is a button labeled by the field `label` plus the current summary text. The popover listbox uses `selectionMode="multiple"` with checkbox affordances on each item. Keep `label` visible, and use `description` / `errorMessage` (the error message is `role="alert"`) so assistive tech gets the same help and validation copy as sighted users.
