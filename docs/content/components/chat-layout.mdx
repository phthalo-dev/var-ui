# ChatLayout

Full chat shell with a scrollable message area above a sticky composer dock. Includes a default scroll-to-bottom / new-messages button wired to `useChatStreamScroll` and `useChatNewMessages`.

## Examples

### Default

There is no `@var-ui/astro` ChatLayout — Astro and HTML previews show a static core-recipe shell; scroll and send behavior are React-only.

<Demo id="chat-layout.default" />

## Bounded height

By default the root is `flex: 1; min-height: 0`, made for a full-height flex parent. Pass
`maxHeight` (any CSS length — `20rem`, `50dvh`) to bound the shell inside a page section;
the message area scrolls within it.

## Accessibility

The message list uses `role="log"` with `aria-live="polite"`. Pass `streaming` to `ChatMessageList` so screen readers announce completed messages once during streaming.
