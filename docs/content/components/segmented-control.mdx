# SegmentedControl

Segmented toggle group for mutually exclusive options. Built on React Aria `ToggleButtonGroup` with an animated indicator. Prefer this over a row of standalone `ToggleButton`s when only one choice should be active.

## Examples

### Default

## Accessibility

Each segment is a toggle button inside a group; keyboard users can move between segments with arrow keys (React Aria). For icon-only options, set `aria-label` on the option. Options are `{ value, label, disabled? }`; the control is always single-select.
