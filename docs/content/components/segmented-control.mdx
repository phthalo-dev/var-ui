# SegmentedControl

Segmented toggle group for mutually exclusive options. Built on React Aria `RadioGroup` with an animated indicator. Prefer this over a row of standalone `ToggleButton`s when only one choice should be active.

## Astro: change event and `name`

In Astro, the control dispatches a bubbling `var-ui:segmented-control-change` event (`SEGMENTED_CONTROL_CHANGE_EVENT` from `@var-ui/astro`) on its root when the user picks a segment; `event.detail.id` is the chosen option's `value`. `setSegmentedControlValue(root, value)` updates the selection from script without firing it.

```ts
import { SEGMENTED_CONTROL_CHANGE_EVENT } from '@var-ui/astro';

root.addEventListener(SEGMENTED_CONTROL_CHANGE_EVENT, (event) => {
  const { id } = (event as CustomEvent<{ id: string }>).detail;
});
```

The radios share a `name`, which is also the field name submitted with a form. Without one, Astro derives it from the page path and the control's position on the page, so it is the same on every build; pass `name` when a form reads the value or when you want a fixed name.

## Accessibility

Each segment is a radio button inside a `role="radiogroup"`; keyboard users Tab to the checked option (or the first option when none is checked) and move between options with arrow keys (React Aria). Give the group an accessible name with `aria-label` or `aria-labelledby`. Options are `{ value, label, icon?, disabled?, aria-label? }`; the control is always single-select.

## Icons

An option's `icon` renders before its label. It takes a registry name (`'colorModeDark'`) or, in React, any node; in Astro, `{ svg }` markup (for example a glyph from `@var-ui/icons/glyphs/<name>`). With `layout="icon"` only the icon shows, and the label becomes the segment's accessible name and (in Astro) its tooltip. The same options array works in React and Astro, including when it's built with `map`, which Astro's named slots can't do.

```ts
const options = [
  { value: 'list', label: 'List', icon: 'menu' },
  { value: 'grid', label: 'Grid', icon: { svg: gridSvg } }, // Astro; in React pass <GridIcon />
];
```
