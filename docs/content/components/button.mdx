# Button

Triggers an action or event. With `href`, Button renders React Aria's `Link`, so it honours [`RouterProvider`](/docs/getting-started#routing) for client-side routing.

## Examples

### Default

The default button uses `tone="neutral"` and `appearance="subtle"`.

<Demo id="button.default" />

### Variants

Use `tone` and `appearance` to control color and surface treatment — the same vocabulary as `Badge`, `Alert`, and `Banner`.

- **tone** — `neutral`, `accent`, `success`, `warning`, `danger`, `info`
- **appearance** — `solid`, `outline`, `subtle`, `ghost`

Each row below is one appearance; each button in the row is a different tone.

<Demo id="button.variants" />

### Sizes

`size` (`xs`, `sm`, `md`, `lg`, `xl`) falls back to the surrounding control size, then `md`, so a button inside an `InputGroup`, a `Toolbar` or a `Select.Root` matches its neighbours without its own `size`.

<Demo id="button.sizes" />

`xs` is for dense rows, tags and code-block headers. Its box is 20px, under the 24px minimum target in WCAG 2.2 (2.5.8), so an invisible layer grows the pointer target to 24px without changing layout. Leave at least 4px between neighbouring `xs` buttons so their targets don't overlap. `xs` and `xl` are button-only: text inputs and selects stop at `sm`–`lg`.

### Disabled

Pass `disabled` to remove the button from the tab order and block press events.

<Demo id="button.disabled" />

## HTML

Set `data-tone` and `data-appearance` on a `.var-ui-button` element (plus `data-size` and `data-layout` when needed). In TypeScript, use `button({ tone, appearance })` from `@var-ui/core`.
