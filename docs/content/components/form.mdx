# Form

Native-constraint form that focuses the first invalid field. `Form` is a React `<form>` that runs `checkValidity()` and accepts a server `errors` map keyed by field `name`. A truthy `errors` entry blocks submit; the app owns clearing it — `Form` does not reset `errors` when the control changes.

There is no `@var-ui/astro` Form. Native `required` works in Astro without `Form`; focus-first-invalid is React-only.

## Server errors

Pass an `errors` map keyed by field `name`. A truthy entry blocks submit until the app clears it.

```tsx
<Form errors={{ email: 'Enter a valid email' }}>
  <TextField name="email" label="Email" />
</Form>
```

## Using with react-hook-form

`Form` also wraps a react-hook-form `handleSubmit(fn)` and its `setError` for server errors; `register()` works on the text fields, `Checkbox` and `Switch`, and `Controller` covers `Select`, the date fields and the other composite controls. See the [Forms guide](/docs/forms) for the table, Zod with `zodResolver`, and verified examples.

## Accessibility

Form is React-only; native `required` works in Astro without `Form`. On invalid submit, focus moves to the first `[aria-invalid="true"]` or `:invalid` control.
