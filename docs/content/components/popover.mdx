# Popover

Click-triggered panel for short interactive content. Unlike `Tooltip` / `HoverCard`, it opens on press and can host actions. `Popover` is the compound Root (`Popover.Trigger`, `Popover.Popup`, `Popover.Close`, `Popover.Title`, `Popover.Description`, `Popover.Content`). The trigger child must forward DOM props (`popovertarget`) — there is no `render` prop.

The popup is a native `<div popover="auto">` rendered in place: it sits in the top layer (so it works inside a modal `<dialog>`), is positioned with CSS anchor positioning and light-dismisses on an outside press or Escape. Pass `placement` (`top`, `bottom`, `start`, `end`, optionally with an alignment such as `bottom end`) and `offset` (px or any CSS length, written to `--var-ui-popup-offset`). There is no arrow part.

State attributes, positioner CSS variables, and `onOpenChange` details are documented in [Overlay lifecycle](/docs/overlay-lifecycle).

## Accessibility

Built on the native `popover` attribute. The trigger is a `popovertarget` invoker, Escape and outside presses close it, and focus returns to the trigger on close. Opening does not move focus into the panel: put `autofocus` on an element inside it when it should take focus. The popup gets `role="dialog"` and an accessible name only when it has a `Popover.Title` or an `aria-label`. Keep content focused — for blocking decisions use `AlertDialog` or `Dialog`.
