# LayoutPanel

Side panel for `Layout` start/end slots. Supports fixed width, `useResizable`
integration, and responsive `overlay` / `hidden` modes below a breakpoint. `overlay` renders the panel in a native modal `<dialog>` that slides in from `data-side` (the same primitive as `Drawer` and `MobileNav`): native focus trap, Escape, backdrop dismissal and scroll lock, with `open` / `defaultOpen` / `onOpenChange(open, details)`.

### Resizable

Pass a `useResizable()` result as `resizable` and set `hasResizeHandle` to get a
`ResizeHandle` on the edge facing the content: after a `start` panel, before an
`end` panel (with the drag direction flipped). It replaces `hasDivider`, and is
skipped below a `responsive` breakpoint. Without `hasResizeHandle`, compose your
own `ResizeHandle` next to the panel.

```tsx
const list = useResizable({ autoSaveId: 'list', defaultWidth: 340 });

<Layout
  start={
    <LayoutPanel resizable={list} hasResizeHandle resizeHandleLabel="Resize list">
      {items}
    </LayoutPanel>
  }
>
  {detail}
</Layout>;
```
