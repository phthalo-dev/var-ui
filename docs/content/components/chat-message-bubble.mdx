# ChatMessageBubble

The chat bubble — a styled content container that reads `sender` from an ancestor `ChatMessage` to auto-style its background and text color. var-ui does zero markdown parsing; pass plain text or your own rendered tree as `children`.

## Examples

### Default

There is no `@var-ui/astro` ChatMessageBubble — Astro and HTML previews use the core bubble recipe (pass `sender` explicitly).

<Demo id="chat-message-bubble.default" />

Use `group` when rendering several consecutive bubbles from the same sender, to tighten the corners between them.

`variant="subtle"` keeps a tinted bubble but drops the solid accent fill on user bubbles
(`tone.accent.subtleBackground` + `text.primary`), so inline content that sets its own
color — links, markdown spans — stays readable. `ghost` drops the background entirely.
