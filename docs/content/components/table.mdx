## Accessibility

Renders a real `<table>`. Mark the identifying column with `rowHeader` (`scope="row"`). Prefer a `caption` (or external heading referenced with `aria-labelledby`) so the table has an accessible name. Sort chrome sets `aria-sort` when you wire `allowsSorting` / `onSortChange`.
