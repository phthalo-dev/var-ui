# Tree

Hierarchical expandable list with APG tree keyboard behavior. Compose nested `Tree.Item`s or pass a recursive `items` array; control expand/selection with `expanded` / `onExpandedChange` and `value` / `onValueChange` (string ids; `string[]` with `multiple`).

### Expanded selection

Seed nested expansion with `defaultExpanded` and highlight a leaf with `defaultValue`.

Selection is named like `Select`: passing `value`, `defaultValue` or `onValueChange` makes rows selectable (a row click selects it and sets `aria-selected`), and `multiple` allows more than one selected row, with `value` as `string[]`. Without any of them a row click toggles expansion.

## Accessibility

Root uses `role="tree"`; nodes are `treeitem` with `aria-level`, `aria-expanded`, and optional `aria-selected`. Provide an `aria-label` (or labelled-by) on the tree. Arrow keys move focus (roving tabindex); Left/Right collapse/expand; Space/Enter select when the rows are selectable.
