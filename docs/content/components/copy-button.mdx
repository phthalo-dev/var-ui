# CopyButton

Copies a value to the clipboard with visual feedback. Defaults to an icon + label button; pass a render-prop `children` function when you need custom chrome.

`CopyButton` from `@var-ui/astro` renders the same button and classes with the same labels, enhanced by a small clipboard script. It takes the same props except the render-prop `children` — custom chrome needs the React component.

## Reacting to a copy

`onCopied(value)` runs after a successful write and `onCopyError(error, value)` when the write fails (permission denied, an insecure context), so you can show your own toast or log the failure. They have their own names because the native `onCopy` is the element's clipboard event. `useCopy` takes the same two options.

```tsx
<CopyButton
  value={url}
  onCopied={() => toast.success('Link copied')}
  onCopyError={() => toast.error('Copy failed')}
/>
```

In Astro, listen for the bubbling `var-ui:copy-button-copied` and `var-ui:copy-button-error` events (`COPY_BUTTON_COPIED_EVENT`, `COPY_BUTTON_ERROR_EVENT` from `@var-ui/astro`); `event.detail.value` is the text.

## Accessibility

The default control is a native `button` whose `aria-label` tracks the current state label (`copyLabel`, `copiedLabel`, or `errorLabel`). After a successful copy, the label updates so assistive tech hears the confirmation. Prefer clear verbs over icon-only copy affordances unless you supply an explicit render-prop with its own accessible name.
