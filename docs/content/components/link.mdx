# Link

Navigates to a URL or route. Renders React Aria's `Link`, so it honours [`RouterProvider`](/docs/getting-started#routing) for client-side routing.

### Quiet navigation link

A link inherits the surrounding font size, so it fits whatever sentence it sits in. For a standalone navigation link ("Back to runs", "View raw"), set a `size`, a quieter `tone` (`primary` or `secondary` text instead of the accent link colour) and a `startIcon` or `endIcon`. Icons are sized to the text and hidden from assistive tech: the link text names the link. In Astro, pass the icon in the `start-icon` or `end-icon` slot.
