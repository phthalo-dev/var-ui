### Link card

Give a `Card` an `href` and the whole card becomes one link (an `<a>`), the same way `Button` does. A link card takes a `title` (required), an optional `description` and a trailing `hint` (a reading time, "Learn more →"); children render between the description and the hint. Keep link cards free of other interactive content: a button or link inside a link is invalid.
