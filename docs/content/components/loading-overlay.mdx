# LoadingOverlay

Blocks pointer interaction over its children while async work runs and shows a spinner. Toggle with `visible`; set `label` for the spinner’s accessible name.

## Accessibility

When `visible`, the root sets `aria-busy="true"`, the children are wrapped in an `inert` element (no focus, clicks or assistive-tech access while loading), and the spinner uses `label` (default `"Loading"`). Keep meaningful content as children so the blocked region remains in the document.
