# Chip

Compact pill-shaped labels. Use `ChipGroup` for coordinated single- or multi-select filter
chips (`multiple` for several, `value` / `onValueChange`), `selected` /
`onSelectedChange` for a standalone toggle chip, or `Pill` / `onRemove` for removable tags.

## Accessibility

Toggle chips render as buttons with `aria-pressed`. Remove controls expose an accessible
dismiss label.
