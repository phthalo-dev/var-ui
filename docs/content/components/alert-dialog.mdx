# AlertDialog

Modal confirmation for important or destructive actions. `AlertDialog` is the compound Root: a `Dialog` with `role="alertdialog"` and backdrop dismissal off (`AlertDialog.Trigger`, `Backdrop`, `Popup`, `Header`, `Title`, `Description`, `Actions`, `Close`). The cancel/confirm arrangement is a recipe you copy, not a preset: confirm is just your button inside `AlertDialog.Close`, so Cancel and Escape never run it. The trigger child must forward DOM props — there is no `render` prop.

State attributes, exit animation, and `onOpenChange` details are documented in [Overlay lifecycle](/docs/overlay-lifecycle).

## Examples

### Default

Destructive confirms use `tone="danger"` and autofocus Cancel so Enter does not confirm by accident.

### Confirm pattern

Non-destructive confirms use `tone="accent"` and `appearance="filled"`. Change the button labels to match the task. To confirm asynchronously, drop the confirm `AlertDialog.Close`, run your work in the button's `onClick`, then close with controlled `open`.

## Accessibility

Renders as an alertdialog with a focus trap. Destructive flows autofocus Cancel so Enter does not immediately confirm. Escape and the cancel button dismiss without calling `onConfirm`. Prefer a clear `title` and short `description` that name the irreversible consequence.
