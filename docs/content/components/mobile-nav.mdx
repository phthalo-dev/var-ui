# MobileNav

Slide-out mobile navigation drawer built on React Aria Modal — focus trap, Escape, and backdrop dismissal included. Like every overlay it takes `open` / `defaultOpen` / `onOpenChange(open, details)` (`details.reason` is `escape-key`, `outside-press`, `close-press`, `trigger-press` or `imperative`; `details.cancel()` vetoes the change), and it animates out. Or share state through `MobileNavProvider` + `MobileNav.Toggle`.

## Accessibility

The panel is a dialog (`label` defaults to `"Navigation"`) with a labeled close control. `MobileNav.Toggle` sets `aria-expanded` from provider or explicit `open`, and defaults to `aria-label="Open navigation"`. Prefer the provider pattern when the toggle lives in top chrome and the drawer is a sibling (as in `AppShell`).
