# Documentation

Guides for installing, configuring, and building with var-ui. Use the sidebar to move between topics.

## What you'll find here

- **Getting started** — create a project and render your first component
- **Overlay lifecycle** — native dialog and popover lifecycle, state attributes, enter and exit in CSS, and `onOpenChange` reasons
- **Hooks** — reference for `useDisclosure`, `useHotkeys`, `useClickOutside` and every other public hook
- **Forms** — native validation and `Form`, react-hook-form and Zod, server errors, async submit, and Astro
- **Installation** — package setup for React apps in the monorepo or downstream

More guides will land here as the design system grows.
